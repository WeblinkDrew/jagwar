## License and attribution

The baseline is Apache-2.0. Distribution must include the license, mark modified files appropriately, retain relevant copyright/patent/trademark/attribution notices, and preserve any applicable NOTICE content. Audit copied/adapted dependencies, assets, icons, and styles before inclusion. The documents generated by this scan do not copy donor/reference code or assets.

## Pull-request evidence

Include:

- problem and authority owner;
- new-file versus protected-original classification;
- exact approved Core Change Requests;
- migrations and rollback;
- authorization and tenant-boundary analysis;
- focused tests and commands run;
- baseline capability regression evidence;
- unresolved story-specific OD gates and protected-file approvals.
